# Cal Poly Rec Center Usage Prediction

Machine learning project that predicts Rec Center crowding from historical Occuspace occupancy data (30-minute intervals, May 2023–April 2026).

## Problem

Students and Rec Center staff need reliable estimates of how busy each area will be at a given time. We predict:

- **Regression:** `Average Utilization` (0–1, occupancy relative to capacity)
- **Classification:** Low / medium / high usage categories for student-friendly recommendations

## How to run

1. Install dependencies:
   ```bash
   pip install -r rec_center/requirements.txt
   ```
2. Run notebooks in order from the repository root or `rec_center/` folder:
   - `01_data_cleaning.ipynb` — builds `data/rec_center_clean.parquet`
   - `02_eda.ipynb` — exploratory analysis figures
   - `03_regression_modeling.ipynb` — baselines, tree/boosting/NN models, ensemble
   - `04_classification_modeling.ipynb` — low/medium/high usage classifiers

Each notebook is self-contained with markdown section headers and saved outputs.

To regenerate report figures and `data/metrics.json` without a full re-tune:

```bash
python run_report_artifacts.py
```

Key figures include `feature_importance_regression.png`, `train_window_sensitivity.png`, and EDA plots referenced in the final report.

## Student forecast dashboard

Interactive **Streamlit** app: enter class schedule, earliest start time, latest finish time, and preferred workout area → get a recommended gym time each day (plus alternates). Includes a busyness explorer by location and hour.

1. Ensure `data/rec_center_clean.parquet` exists (run notebook 01 or `run_report_artifacts.py`).
2. Train and save the forecast model:
   ```bash
   cd rec_center
   python train_forecast_model.py
   ```
3. Launch the dashboard:
   ```bash
   streamlit run dashboard/app.py
   ```

Use **My Gym Plan** for personalized recommendations (7-day or custom date range). Use **Busyness Explorer** to view predicted crowd levels without a schedule.

## Modeling highlights

- **Time-based train / validation / test split** (no random shuffling) to simulate forecasting future usage
- **Models compared:** historical mean baseline, Ridge regression, Random Forest, LightGBM, CatBoost, Keras MLP, stacking ensemble
- **Metrics:** RMSE, MAE, R² (regression); accuracy and macro-F1 (classification)
- **Individual learning extensions:** academic calendar feature ablation, Optuna hyperparameter search, stacking ensemble analysis

## Individual learning (group of 3)
